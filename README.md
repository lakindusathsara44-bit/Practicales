# Practicales — HNDIT1012 Windows Forms Practicals

A focused learning site and Visual Studio solution for **HNDIT1012 – Visual Application Programming**, based on the supplied Week 1 and Week 2 class presentations.

## Included
- Week 1: programs, source code, compiler/interpreter, .NET Framework, Visual Studio 2022, Windows Forms project setup and Hello World button/label event.
- Week 2: TextBox, Button and Label controls, Properties window, Click events, string concatenation, Int32.Parse(), ToString(), C# data types and operators.
- Two native C# Windows Forms projects:
  - `CSharp/WinForms/Week1HelloWorld`
  - `CSharp/WinForms/Week2Calculator`

## Open the native Windows Forms projects
1. Open `CSharp/WindowsFormsPracticals.sln` in Visual Studio.
2. Select `Week1HelloWorld` or `Week2Calculator` as the startup project.
3. Press **F5** to build and run.
4. The projects target **.NET Framework 4.0** and use C# 4.0-compatible syntax.

## Run the learning website
Open `index.html` in a browser, or publish the repository root with GitHub Pages. No Node.js, npm, React, Vite or build step is required.

## Scope
This repository is intentionally limited to the Windows Forms practicals in HNDIT1012 Week 1 and Week 2. Console application and Web Design lessons have been removed from this learning space.
